# Programmes

### Overview

In addition to the country platforms, uSupport hosts programmes. A programme is a separate website on the uSupport platform, built around a specific initiative, audience and set of resources. The content of each programme is managed in the uSupport CMS.

Programmes are not variations of the country platforms. Each programme has its own structure and features, which are described on the programme’s page in this section.

The following programmes are currently available:

* Play and Heal (https://playandheal.usupport.online) – a play-based psychosocial support toolkit for facilitators working with children affected by crises, and for caregivers.
* Hosn El Hal (https://teacher.wellbeing.usupport.online) – short, practical wellbeing resources for teachers and education staff.
